# Krea Actor Reference Prompt Guide

Create a stable visual identity for one actor as a four-panel character reference image.

- Describe only physical appearance and wardrobe, not a scene, story, action, emotion, or dialogue.
- Include ethnicity or setting-appropriate appearance, face shape and features, skin tone, hair, body type, stature, approximate age, and distinguishing marks.
- Use concrete, era-appropriate clothing and materials.
- Keep the same face, body, hair, wardrobe, and colors in every view.
- Write one concise English image prompt with no headings, JSON, Markdown, or camera movement.
- End exactly with: `Four vertical panels in one image, full body front view, three-quarter face, close-up face, full body profile, white seamless background, neutral expression, consistent face, consistent wardrobe.`

# Krea Location Reference Prompt Guide

Create one continuous environment reference image for a location.

- Describe only physical environment, production design, objects, textures, materials, lighting, and atmosphere.
- Include enough architectural and spatial detail for visual continuity in later scenes.
- Use a wide establishing view with no characters, action, narrative, text, collage, split screen, or panels.
- Write one concise English image prompt with no headings, JSON, Markdown, or camera movement.
- End exactly with: `Wide establishing view, production design, lighting, atmosphere, single continuous image, no collage, no split screen, no panels, no people, no text.`

## Production consumers / reachability
- JsonArtifactStore is the canonical artifact reader used by plan_stages, render_stages, render_video, generate_render_plan, movie_pipeline_jobs, adapters/movie_minimax_visual, tools/repair_scene_srt, etc.
- Direct utf-8-sig reads are used in pipeline stages that process `state.plan_for_next_step`, `state.context.resolved_context`, and resume plan loading.
- External audit issues confirm BOM is a real production problem:
  - #1323 AppConfig.load reads app_config.json with plain utf-8; BOM crashes every CLI entry point
  - #1316 compact_relay_prompts and fix_ltx_prompt_anchors reject BOM-prefixed render plans
- CanonicalPlanStore already reads with `raw.decode("utf-8-sig")` lines 42,56.
- No writer in the repo emits UTF-8 BOM; atomic_write_json writes utf-8 without BOM.

## Behavior equivalence
utf-8-sig is a strict superset of utf-8 for decode: it strips a leading BOM if present and otherwise behaves identically. Changing JsonArtifactStore to utf-8-sig is behavior-preserving for all existing utf-8 files and fixes BOM crashes.

## Architectural owner
Central JSON I/O lives in `feverslop.utils.io` and `feverslop.adapters.local_artifacts.JsonArtifactStore`. A single `read_json` helper with utf-8-sig is the appropriate owner, not scattered `read_text(encoding="utf-8-sig")` calls.

## Coupling / boundary assessment
Consolidation to a central reader does not increase coupling; it reduces it. All pipeline stages already depend on JsonArtifactStore or utils.io. No bounded-context violation.

## Expected reduction / benefit
- Eliminates 11+ ad-hoc utf-8-sig reads and prevents future drift
- Unifies BOM tolerance with AppConfig and CanonicalPlanStore conventions
- Aligns with issues #1323 and #1316 remediation

## Behavior-change expectation
none intended for valid utf-8 files; BOM files become readable instead of raising JSONDecodeError

## Risks
Low. utf-8-sig decode is safe for BOM-less files. Existing tests using utf-8-sig will continue to pass. Public API of JsonArtifactStore unchanged semantically.

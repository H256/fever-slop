# Code of Conduct

FeverSlop is intended to be a constructive, technical open-source project.
Participants must act respectfully, discuss ideas rather than people, and
accept good-faith technical disagreement.

Unwelcome behavior includes harassment, discrimination, threats, personal
attacks, deliberate disclosure of private information, and disruptive
conduct. Maintainers may edit, reject, or remove contributions that violate
these expectations.

Report conduct concerns privately to the repository maintainers rather than
posting sensitive details in a public issue.
